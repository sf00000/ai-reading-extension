# AI 翻译助手（浏览器插件）

网页内直接完成 **AI 翻译 + AI 总结**：选中文字右键翻译/总结、一键整页双语翻译、结果展示在**可拖动悬浮窗**中，完全不打断阅读。支持 DeepSeek 等任意 OpenAI 兼容大模型，也可切换**谷歌翻译**（免费免 Key）。相同段落自动走本地缓存，**不重复调用大模型、不重复消耗 token**。

## 功能一览

| 功能 | 入口 | 说明 |
|---|---|---|
| 划词翻译 | 选中文字 → 右键「AI 翻译助手」→ 翻译选中内容 | 结果显示在悬浮窗 |
| 划词总结 | 选中文字 → 右键 → 总结选中内容 | 按设置页的自定义提示词执行 |
| 整页翻译 | 工具栏弹窗「翻译本页」/ 快捷键 **Alt+T** / 右键菜单 | 逐段在原文下方插入译文（双语对照），再触发一次即恢复原文 |
| 整页总结 | 弹窗「总结本页」/ 右键菜单 | 提取正文发给大模型 |
| 目标语言 | 弹窗下拉 / 设置页 / 悬浮窗右上角下拉 | 9 种语言，切换即生效 |
| 翻译服务 | 设置页 | 大模型（DeepSeek / Kimi / 通义 / GLM / OpenAI…）或谷歌翻译 |
| 总结语言 | 悬浮窗内切换 / 设置页 | 总结可独立于翻译目标语言 |
| 自定义总结 Prompt | 设置页 | 支持 `{{lang}}`、`{{text}}` 占位符 |
| 段落级缓存 | 自动 | 见下文「缓存机制」 |

## 悬浮窗

- 顶部标题栏可**按住拖动**到任意位置，不遮挡固定区域时可随手挪开
- 两个 Tab：「翻译」/「总结」，划词后可在同一窗口随时切换
- 右上角语言下拉：**切换语言立即重新执行**（总结与翻译共用，翻译即目标语言、总结即输出语言）
- 底部「复制」一键复制结果；带 ⚡ 标记表示本次结果来自缓存

## 缓存机制（省 token 的关键）

缓存键 = `翻译服务 + 目标语言 + 模式(翻译/总结) + 提示词指纹 + 文本指纹`

- 按**文本内容**匹配而非仅按链接：同一链接再次打开相同段落 100% 命中；不同网站出现相同段落也能命中
- 整页翻译时未命中的段落会**批量合并**成一次大模型请求（每批最多 8 段），比逐段调用省得多
- 总结缓存同时计入所用 Prompt——改了提示词会自动重新总结
- 设置页可查看缓存条数/大小并一键清空；存储使用 `chrome.storage.local`（申请了不限容量权限），Key 不出本机

## 谷歌翻译说明

**可以**，已内置为可选翻译服务：走 `translate.googleapis.com` 免费网页端接口，**无需申请任何 API Key**，速度快、零成本。权衡：

| | 谷歌翻译 | 大模型翻译 |
|---|---|---|
| 费用 | 免费 | 按 token 计费 |
| 速度 | 快 | 稍慢（批量请求） |
| 质量 | 直译风格，无上下文理解 | 术语/上下文/语气更好 |
| 总结功能 | ❌ 不支持（总结必须用大模型） | ✅ |

适合组合用法：日常整页浏览用谷歌翻译，划词精翻和总结用 DeepSeek 等。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 右上角开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本目录 `ai-translate-extension`
4. 打开插件设置页（弹窗右上角 ⚙️）：
   - 点击服务商预设（如 DeepSeek）→ 填入 API Key → 「测试连接」
   - 或将翻译服务切到「谷歌翻译」，无需 Key 即可用
5. 任意网页选中文字右键，或按 Alt+T 体验

> 首次保存 API 配置/测试连接时，浏览器会请求该 API 域名的访问授权，请点「允许」。API Key 仅存本机扩展存储。

## 实现说明

- **权限最小化**：不声明 `<all_urls>` 常驻注入，内容脚本在用户触发（弹窗/右键/快捷键）时经 `chrome.scripting` 按需注入；仅谷歌翻译域名是静态 host permission
- **API 调用全部在后台**完成（Service Worker 持有 host 权限），内容脚本只收发消息，避免页面 CSP/CORS 干扰
- **整页翻译跳过规则**：代码块、`<pre>/<code>`、导航/评论类 class、已是目标语言的段落（CJK 比例启发式）自动跳过；表格单元格内追加译文避免撑坏表格
- **批量翻译容错**：批量请求失败时自动降级为逐条翻译；单条失败不中断整体
- 悬浮窗使用 **Shadow DOM**，样式与宿主页面完全隔离

## 已知限制

- 整页翻译对 SPA 动态加载的新内容需再次触发；`chrome://` 等浏览器内部页面无法注入
- 谷歌翻译免费接口非官方 API，极端情况下可能限流；超长段落（>5000 字符）为稳妥起见被跳过
- 目标语言判定用启发式（CJK 字符比例），个别混排段落可能被跳过，属预期行为
